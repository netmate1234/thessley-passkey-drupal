Flow

Four steps, no shared secret

1

Request

The module mints a one-time id, nonce and origin with a short life.

2

Scan

The QR or tap link hands the request to the app.

3

Sign

The device lock authorises an ECDSA P-256 signature.

4

Verify

The module checks the enrolled key and origin, then issues the session.

thessleypublic key only, nothing replayable
Modules

Two modules, one protocol

thessley_passkey

  • QR / one-tap login on /user/login.
  • Optional, password-then-app, or app-only.
  • Per-user device list, attestation, revocation.

thessley_windows_access

  • Distributed Windows account enrolment.
  • PAM sign-in approvals.
  • Group-based resource access; depends on the passkey module.

Install

Copy, enable, configure

git clone https://github.com/netmate1234/thessley-passkey-drupal.git /tmp/thessley-drupal
cp -r /tmp/thessley-drupal/thessley_passkey /path/to/drupal/web/modules/contrib/
cp -r /tmp/thessley-drupal/thessley_windows_access /path/to/drupal/web/modules/contrib/
drush en thessley_passkey thessley_windows_access && drush cr

Then open /admin/config/people/thessley-passkey and choose a login method. The verify step: /user/login shows the QR box and an enrolled phone can sign in.
